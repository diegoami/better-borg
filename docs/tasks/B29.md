- **Semantic choices forced by the host and the facts** (each flagged in
  the commits):
  1. **`event:turn` does not exist in API 2 at this pin** - the engine's
     event map carries no turn event and an `on("turn")` is refused as
     unknown, so the demonstration log rides `event:player-command` (the
     per-command event the web shell emits, main.ts:8619) and renames the
     day upstream adds a turn event. The issue's "one capability line"
     became that line.
  2. **The mod cannot know T (the death turn)** - no seed seam
     (neo-angband#431), so the human path's settings carry the two numbers
     the DOSSIER prints (release boundary turn, recorded death turn); the
     owner copies them, the mod composes the banner.
  3. **Rungs are turn-offsets; boundaries are decisions.** The autoplayer
     stops only at decision boundaries, so a rung whose target falls
     inside one decision (the killing decision of a fast death can spend
     more turns than the smallest rung - seed 34's spent 8) has NO release
     point: listed `none` in the ladder, never a post-mortem snapshot.
     Two rungs can share a boundary; the dossier names the boundary turn,
     so sharing is visible.
  4. **The message tail is a bound sink, proven neutral.** Recorded
     sessions booted message-less; the replay binds `state.msg` so the
     dossier carries the tail. Every engine call site is an optional call
     (`state.msg?.(...)` - verified at the pin), and the exactness test
     pins the neutrality on the committed record.
  5. **A diverged replay still writes its dossiers, DIVERGED-stamped** -
     the evidence is honest about what it is; the verification names every
     difference (cause, turn, decisions, census, level, depth).
